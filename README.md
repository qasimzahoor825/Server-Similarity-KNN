
# Server Similarity & CPU Prediction using KNN

Simulates server CPU, Memory, and Network traffic data, analyzes similarity between servers using KNN and Euclidean distances, visualizes metrics with heatmaps/clustermaps, and predicts next-interval CPU usage via KNN regression.

## Features
- Simulate server performance data
- Compute server similarity with KNN
- Visualize CPU, Memory, Network with heatmaps
- Predict CPU usage for the next interval using KNN regression

## Technologies
- Python, Numpy, Pandas
- scikit-learn
- Matplotlib, Seaborn

## Usage
```bash
pip install -r requirements.txt
python scripts/server_knn.py
```
